## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders exactly as they are.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** branch and **/(root)** folder.
6. Save.
7. Wait a minute. Your site will be live at:
   `https://yourusername.github.io/repository-name/`

## Notes
- The website includes a language switcher (EN / GR).
- Contact actions point to phone, email, WhatsApp, Instagram and Facebook.
- The articles section uses the provided poster images.
- Replace or add images inside `images/` anytime.
